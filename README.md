電商網站模擬專案
GitHub Pages | GitHub

製作目的：

模擬實際的電商網站流程，從前台商品呈現，到後台訂單及商品管理。實作前端 React與後端 API 的溝通，並以 RWD 設計滿足近代跨裝置需求。 

網站功能：
購物車
送出訂單
收藏清單
訂單查詢

主要負責項目：

負責購物車與訂單模組的開發，前端與後端的 API 溝通及資料管理。

技術實作：

透過 Axios 串接後端 RESTful API 建立前後端溝通，即時更新購物車資料；

使用 React Router 管理路由，優化使用者體驗；

使用 React Hook Form 快速開發表單，整合錯誤提醒及限制。

使用技術：

前端： React、Bootstrap
工具： Create React App
套件： React Router、React Hook Form 、Axios
